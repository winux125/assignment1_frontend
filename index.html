About me

I started with HTML because it is the part of the web you can see immediately. Writing a tag and reloading the page is a very short feedback loop, and that makes it easy to learn by experiment instead of only by reading.

CSS was the harder half for me. The markup describes what a thing is, while the stylesheet decides how it looks and where it sits. Keeping those two jobs separate is the point of linking an external styles.css instead of writing inline styles.

Outside of study I read about typography, play chess badly, and take long walks around Astana when the weather allows it.

What I want to learn this semester

  1. Write semantic HTML without reaching for a div every time.
  2. Understand the box model well enough to debug layout by reading the CSS.
  3. Build a responsive page that works on a phone without a framework.
  4. Learn CSS positioning, floats, Flexbox and Grid, in that order.
  5. Publish every project so it has a real URL.
