Laying out a page without Flexbox

Before Flexbox existed, a two column page was built by floating one block to the left and the other to the right, then clearing the float so the footer would not slide up underneath them. The parent div here has a fixed order in the markup, and the floats decide which side each column ends up on.

Why clearing matters

A floated element is taken out of the normal flow, so its parent collapses to zero height if every child is floated. The fix is a block after the columns that clears both sides, which is what the empty clear div at the end of this section does.

Positioning

The small badge in the corner of this box uses position: absolute against a parent with position: relative, which is the other half of pre-Flexbox layout work.

Visual separation

Each section gets its own background colour, padding, border and box shadow so the boundaries are readable without any layout framework. The header, navigation bar and footer are styled to match the other task pages, only the rules behind them avoid Flexbox.
